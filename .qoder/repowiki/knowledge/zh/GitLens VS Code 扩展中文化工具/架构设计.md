- 核心入口：`translate.py` 作为主 CLI，提供 `install`（覆盖用户本地扩展目录的 `package.json`）、`restore`（从备份恢复）、`extract`（对比英文版与部分翻译版生成未翻译清单）及 `stats`（统计覆盖率）等命令。
- 数据层：`data/` 存放多版本 JSON 资产（`package-v18-en.json` 为英文原版，`package-v18-zh-partial.json` 为待完善的中译版，`package-v17-zh.json` 与 `contributions-zh.json` 作历史参考）。
- 辅助脚本层：`scripts/` 包含针对特定字段（如命令标题、配置描述）的精细化提取与应用脚本（如 `apply_translations.py` 采用基于索引的文本替换以保留原始缩进格式），形成对主流程的补充。
- 部署方式：通过 `install.sh` / `install.bat` 等包装脚本调用 Python 核心逻辑，直接操作用户环境下的 `.vscode/extensions` 目录实现热更新。
